## 技术决定

1. **Open interval** pakai date-string comparison, bukan datetime
   - 理由: Trip hanya simpan YYYY-MM-DD, tidak ada waktu per trip
   - 影响: Semua trip di hari yang sama dgn fill-up ikut terhitung (termasuk yg sebelum isi bensin)
   - Trade-off yang diterima user: lebih baik over-count daripada miss trip

2. **Spare Parts: current odometer** diestimasi dari fuel log terakhir
   - 理由: Tidak ada real-time odometer tracking
   - 影响: `estOdometer()` pakai `Math.max` dari semua fuel log odometer per vehicle (vms.html:1934)

3. **Multi-type maintenance** store sebagai array `m.types`, backward compat dgn `m.type` string
   - 影响: Display logic cek `Array.isArray(m.types)` dulu (vms.html:1856)
